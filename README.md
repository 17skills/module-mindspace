# Canvas Spark

ich speichere durch copy&Paste von LInks zu Youtube oder podcast Episoden, Upload von PDFs, PPTx oder TXT, MD Inhalte wie Module auf einem React Canvas (oder alternative). Dann verbinde ich die Inhalte untereinander oder mit einem Chatfenster (auch ein Modul) und kann nach Auswahl eines LLms mit den Inhalten interagieren. Ich kann ebenso Inhalte in Frames zu Gruppen kombinieren und mit anderen Inhalten verbinden. 

So könnte ich zB aus den Inhalten Outlines für einen LinkedinPost erstellen oder ganze Posts; ich könnte aber auch eine Summary aller Inhalte erstellen lassen. Alles durch Fragen in ein Promptfenster (Auch ein Modul)

Ich könnte zudem nach erfolgreichen Videos zu einem Thema bei Youtube suchen und die 10 besten Videos (nach Aufrufen) als Gruppe importieren und mit ihnen arbeiten. 

Letzendlich könnte ich mir auch auf Basis eines Figma-Markenhandbuchs (auch ein Modul, welches ich per MCP eingebunden habe) in Verbindung mit den Inhalten eine PPT erstellen lassen. Ich kann aber auch x-beliebige mcp Server einfach als Modul laden und es erscheint als Modul auf dem Canvas. Letztendlich hate es zudem noch die wichstigsten Funktionen von MIRO oder ähnlichen Whiteboards.  

Plane das, bei Fragen, stelle sie
